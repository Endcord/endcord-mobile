# Plugins left out on purpose

These Endcord PC plugins were not ported because of what they do, not because of technical limits.

| Plugin | Status | Notes |
| --- | --- | --- |
| AntiSoap (hideSoap) | Skipped | Hides messages from people of a religious/ethnic group. Hateful content is not shipped in Endcord mobile. |
| SpotifyCrack | Skipped | Circumvents Spotify Premium restrictions (paid features). |
| PullUserIntoVoice | Skipped | Repeatedly forces another user into a voice channel, which works as harassment tooling. |
