# Batch 02: commands (a)

Slash command plugins from Endcord PC. Command and option descriptions stay in English, as on Endcord PC;
replies, toasts, dialogs and settings are translated. Shared helpers live in `com.endcord.plugins.commandscommon`.

| Plugin | Status | Notes |
| --- | --- | --- |
| AvatarGrabber | Ported | `/avatar [user]` sends the 1024px avatar link (GIF for animated avatars, the default avatar for users without one). Users that aren't cached, such as a pasted id, are fetched from the API. |
| BoldText | Ported | `/bold`, same letter and digit mapping as PC. |
| Calculator | Ported | `/calc` uses its own parser instead of JavaScript `eval`: `+ - * / %`, `**`, unary minus and parentheses with JavaScript precedence, and results printed the way JavaScript prints numbers. Same character whitelist and error replies as PC. |
| ClapText | Ported | `/clap`. |
| LeetText | Ported | `/leet`, same letter swaps as PC. |
| SpaceOut | Ported | `/spaceout` spaces out characters by code point, so emoji stay intact (PC splits them in half). |
| Starify | Ported | `/starify`. |
| VibeCheck | Ported | `/vibe`, same ten vibes. |
| ShipCalc | Ported | `/ship a b` uses PC's exact hash, so a couple gets the same score on PC and mobile. |
| GoogleThat | Ported | `/googlethat`, with PC's settings: hyperlink, embed, search engine and custom engine URL. |
| WikiLookup | Ported | `/wiki` reads the English Wikipedia summary API and answers only to you. A missing article, a disambiguation page and a network failure each get their own reply. |
| MoreCommands | Partial | Ported: systeminfo, getuptime, gettime, choose, rolldice, flipcoin, ask, randomanimal, randomnumber, transform, wordcount, countdown, nekos, anime-boys, ping, lenny, mock, slap, freaky, morse, uwuify and all 23 kaomoji commands, plus the "freaky ending" and "uwuify every message" settings (uwuify applies to sent and edited messages). Mobile differences: `/systeminfo` reports the Android version, device, CPU cores, RAM, screen, languages and network; `/getuptime` is the phone's uptime; `/rolldice` takes an integer `sides` option; `/transform` caps the repeated text at 4000 characters; network commands reply with an error instead of failing silently. Not included: `/echo` (Aliucord already has the same `/echo`), `/gifroulette` (the legacy app has no favourite GIFs), `/friendcloud` and `/imgtogif` (not ported), and the "uwuify all text" setting (it rewrites every rendered string, which has no counterpart on the Android views). |
| CustomCommands | Ported | Tags are slash commands with `{{argument}}` and `{{argument = default}}` placeholders plus an `ephemeral` option, as on PC. `/tags create tag-name message` replaces PC's creation modal (`\n` in the message becomes a line break), `/tags list` and `/tags delete` work as on PC, and the settings page can create, edit and delete tags in dialogs. Names are lowercased and checked so a tag can't replace another command. Tags made on PC aren't imported. |
| RemindMe | Ported | `/remindme amount unit text` shows an Android notification instead of a desktop one; tapping it opens the channel the reminder was set in. An exact alarm wakes the phone on time while the app process lives, with a one minute fallback check. Reminders are saved, and any that came due while the app was closed fire on the next start (PC drops ones more than a minute late). Without notification permission the reminder appears in the chat instead. A settings button clears all pending reminders. |
| AtSomeone | Partial | `@someone` in a sent or edited message becomes a mention of a random cached member of the server, or a random DM recipient, like PC. Not ported: the `@someone` entry in the mention autocomplete and its highlight in the chat box, which are patches on desktop React components. Addresses like `name@someone.com` are left alone. |
| DecodeBase64 | Ported | A "Decode Base64" entry in the message long-press menu, shown only when the message has base64 that decodes to readable text. One result opens a dialog with a copy button; several results open a list where tapping one copies it. PC's left/right click setting doesn't apply to touch. Text is decoded as UTF-8 (PC shows non-ASCII text garbled). |
| UnitConverter | Ported | A "Convert Units" entry in the message long-press menu, shown when the message has units to convert, opens the converted text in a dialog with a copy button (PC shows it under the message). Same "your units" setting. Fixes several PC conversion mistakes: inches to cm, metres to feet, pounds plus ounces, km/h being read as km, and units matched inside words. |
| FriendInvites | Ported | One command with subcommands, `/friendinvites create`, `/friendinvites view` and `/friendinvites revoke`, because the legacy app can't run command names that contain spaces. Uses Discord's `/users/@me/invites` endpoints directly; API errors are shown with Discord's message. |
| SpotifyShareCommands | Ported | `/track`, `/album` and `/artist` read the track Discord already tracks for your Spotify status, so they need Spotify connected to Discord and Spotify's "Device broadcast status" setting turned on, the same as Discord's own Spotify presence. |
| InRole | Partial | `/inrole role` lists the cached members of a role (up to 100 mentions, then a count) in a reply only you see. The message long-press menu gets "View Members in Role" for messages that mention a role, opening a member list where tapping a name opens their profile. The role context menu doesn't exist on mobile. Same limitation as PC: the app only knows members it has loaded, so offline members of large servers are often missing. |
| petpet | Ported | `/petpet` builds the same 10 frame headpat GIF as PC from an attached image, the `url` option or a user's avatar (server avatar unless `no-server-pfp`), and sends it. The legacy app has no attachment options, so the image is attached with the normal attachment button and isn't sent along with the GIF. `delay` (at least 20 ms) and `resolution` (16 to 512) as on PC. The hand frames are downloaded from the same GitHub source once and cached. |
