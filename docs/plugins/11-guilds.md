# Batch 11: servers and channels

Plugins that change the server list, the channel list, the direct messages list and the server long-press menu. They
share three helpers in `com.endcord.plugins.guildscommon`:

* **`ChannelListHooks`**, one set of hooks on the channel list. Lists are rewritten at the model level, right after
  `WidgetChannelListModel` built them (`guildListBuilder` for servers, `getPrivateChannelList` for DMs), so collapsed
  categories, unread indicators and positions stay Discord's own. It also decorates channel rows after they are bound,
  lets plugins handle channel taps before Discord opens the channel, and can rebuild the visible list when a setting
  changes.
* **`GuildListHooks`**, one set of hooks on the server list (`WidgetGuildsListViewModel`). Plugins change the
  server/folder entries the rows are built from. When you drag a server, the order Discord saves is fixed first, so
  hidden servers go back where they were and pinned copies are never saved into your folders.
* **`GuildMenuActions`**, entries in the server long-press menu (`WidgetGuildContextMenu`), shown above
  "Leave Server". Channel and DM long-press entries use `api.ChannelSheetActions`.

Everything that hides something can be undone from the plugin's settings.

| Plugin | Status | Notes |
| --- | --- | --- |
| ShowHiddenChannels | Ported | Channels you can't view are shown in their real place in the channel list. While Discord builds the list it treats them as viewable, so categories, collapsing and positions work like for other channels. "Plain style with Lock Icon instead" replaces the channel icon with a lock. The second mode dims the row and keeps the normal icon, because the Android row has no free spot for PC's eye icon. "Hide Unreads" (on by default) clears their unread and mention state. Tapping a hidden channel opens a page instead of the channel: what kind of channel it is, its topic or forum guidelines, the last message and creation time, slowmode, bitrate/user limit/region for voice, the age restriction, and the server owner plus every role and member the channel's overwrites (or Administrator) let in. Voice and stage channels open the same page instead of connecting. PC's "allowed users and roles dropdown" setting is gone, since the list is always shown. Forum tags, the default reaction and layout aren't shown because the legacy app has no models for them. Channels only show up in the channel list: threads of hidden channels and search results don't. |
| CleanerChannelGroups | Ported | Removes every channel, thread and voice user under a collapsed category from the list, unread or not. Unlike PC, the channel you have open (or the voice channel you're in) stays visible so the list still shows where you are. Works together with ShowHiddenChannels on mobile; PC marks the two as conflicting. |
| CleanChannelName | Ported | Cleans the name Discord shows for every server channel (channel list, chat header, mentions): same NFKC, small caps, separator and dash steps as PC. Emoji are matched by code point ranges, because Android 7 has no `\p{Extended_Pictographic}`. The text and voice channel settings pages keep the original name, so editing works like on PC. DMs are never changed. |
| ChannelBadges | Partial | Rounded badges after the channel name for text, voice, announcement ("News"), forum, rules, age-restricted (NSFW) and locked (private) channels, with a switch per badge and "Show only one badge per channel". Only text-like and voice rows get badges; stage, thread, category and directory rows don't. Badge labels and colours aren't customisable (PC has a text and colour setting per badge). |
| ServerInfo | Partial | "Server Info" in the server long-press menu opens a page with the server's name, ID, description, owner, creation and join dates, vanity URL, language, counts (members, channels, roles, emojis, stickers, boosts), safety settings and features. Long-press a row to copy it. PC's other tabs (friends, mutuals, blocked and ignored users in the server) aren't ported. |
| ServerListIndicators | Skipped | The Android server list has no free space next to the home button for a counter, and drawing one over Discord's icon wasn't worth the risk for this batch. |
| ServerPinner | Ported | "Pin server to top" / "Unpin server" in the server long-press menu. As on PC, pinned servers show as copies above the server list, followed by a divider, in the order you pinned them, and stay in their folders. The copies can't be dragged or used as drop targets, and they are taken out of the order Discord saves after you drag another server, so your folders never change. "Unpin all servers" in the settings. |
| ServerSearch | Not applicable | The Android app already has a quick switcher (the search button at the top of the channel list) that finds servers and channels. PC's plugin only adds a button for the desktop quick switcher. |
| HideServers | Partial | "Hide Server" in the server long-press menu. Hidden servers are removed from the server list and their folders; a folder disappears when all its servers are hidden. The server you're in stays until you leave it. Settings: "Hidden Servers" shows a checklist to unhide servers, and "Reset Hidden Servers" unhides all. Dragging servers never drops hidden ones from your saved folders. Unlike PC, they aren't hidden from the Android quick switcher, there's no button at the bottom of the list, and folders can't be hidden as a whole. |
| PinDMs | Partial | "Pin DM" / "Unpin DM" in the DM long-press sheet. Pinned DMs move to the top of the DM list, sorted by most recent message or, with the custom order, by "Move Up" / "Move Down" in the same sheet. "Unpin all DMs" in the settings. PC's pin categories (named, coloured, collapsible sections) aren't ported. |
| MessagePeek | Partial | Under each DM the subtitle shows a preview of the last message (first line, mentions and custom emoji by name, "sent a GIF", attachments, voice messages, stickers, "You:" for your own) and how long ago it was sent, as `5m`/`3h`/`2d` like PC. The preview needs the message to be loaded in the app (any DM you opened this session). Otherwise only the time is added to Discord's own subtitle, because fetching every DM's last message would mean one request per DM. "Hide message previews and timestamps for muted DMs and group chats" works as on PC. |
| UnreadCountBadge | Not applicable | The Android app only tracks mention counts. It has no unread message count per channel (PC reads `ReadStateStore.getUnreadCount`, which the legacy stores don't have), so there is nothing reliable to show. |
| ReadAllNotificationsButton | Ported | Long-press the home (Direct Messages) button above your servers to mark every unread server as read. It uses the same request as Discord's own "Mark As Read", one server at a time. A toast reports how many servers were marked. Also available as "Read All" in the plugin settings. There's no extra button, because the server list has no room for one. |
| MemberCount | Skipped | The Android member list already shows how many members are online and offline in its group headers, and the total member count is in ServerInfo. Adding PC's tooltip and voice counts would need a new header in the member list. |
| NoRoleHeaders | Partial | Role headers in the member list are collapsed to zero height and never stick to the top while scrolling. The member list loads members in ranges by row position, so rows are hidden rather than removed. The "Online" and "Offline" headers stay. |
| ShowResourceChannels | Not applicable | The legacy Android app has no server resources section; every channel you can see is already in the channel list. |
| HideSuggestedChannels | Not applicable | The legacy Android app has no "Suggested" channels section. |
| NoOnboardingDelay | Not applicable | The legacy Android app has no server onboarding screens, so there's no delay to skip. |
| NewGuildSettings | Partial | When you join a server (joined in the last 10 minutes, so servers coming back after an outage aren't touched), sends the configured settings: mute, notification level, suppress @everyone/@here, suppress role mentions and suppress highlights. "Apply NewGuildSettings" is also in the server long-press menu. "Mute New Events automatically" and "Show all channels automatically" are left out: the legacy settings request has no field for event notifications, and the app has no onboarding opt-in. |
| FastDeleteChannels | Partial | "Delete Channel" in the channel long-press sheet, shown when you have Manage Channels for that channel. Mobile has no keyboard, so instead of PC's trash icon that appears while you hold a key combination, it asks for confirmation first ("Ask before deleting", on by default; turn it off for PC's instant delete). |
| PermissionFreeWill | Partial | In a channel's permission editor, you can deny or clear permissions on your own roles and your own member overwrite, which Discord greys out to stop you locking yourself out. Permissions you don't have stay disabled, because Discord's server rejects those anyway. PC's onboarding warning doesn't exist on the legacy app. As on PC, this lets you lock yourself out of a channel until an admin fixes it. |
| ShowHiddenThings | Skipped | Most of what it reveals is desktop-only UI that the legacy Android app doesn't have: the invites-paused tooltip, the member mod view and the server discovery search filters. The remaining part, timeout icons in chat for non-moderators, would need its own research into the legacy chat rows and wasn't done in this batch. |
