# Batch 04: messages (part A)

Ports of Endcord PC's message logging, hiding and blocking plugins. Shared code lives in
`com.endcord.plugins.messagesacommon`:

* `ChatListFilter` hides whole messages (before the chat list entries are built from them) or single entries
  such as an attachment or a sticker (after they are built). Filtering happens on the chat list model, so date
  separators, message grouping and the new-messages bar are computed from what is actually shown.
* `MessageRenderHooks` lets plugins change the markdown of a message before it is parsed, add to the parsed
  text, and style the text view, with one set of patches on `processMessageText` / `DiscordParser`.
* `AttachmentSpoilers` covers attachments with Discord's own spoiler cover, revealed by tapping.
* `MessageStoreAccess` reads and republishes the message cache (`StoreMessagesHolder`).

| Plugin | Status | Notes |
| --- | --- | --- |
| MessageLogger | Ported | Deletes and edits are caught in `StoreMessagesHolder`, the cache behind the chat, so logged messages survive scrolling and switching channels until Discord reloads that channel. Deleted messages stay in the chat with a "(deleted)" tag and red text or a red overlay (Delete Style); their attachments, embeds and stickers turn grey. Earlier versions of edited messages are shown above the text in a muted color with Discord's "(edited)" tag (Inline Edits), and every version is listed in a "Message Edit History" page from the long-press menu. "Remove Message History" in the long-press menu removes a deleted message or forgets an edit history. Ignore bots, yourself, users, channels (and their threads) and servers, like on PC. Limits: Log Size (default 500) log entries and edited messages, 25 versions per message. Also includes MessageLoggerEnhanced's ghost ping alerts, log page and optional saved log (see below). Not ported: collapsing deleted messages into a group, "Toggle Deleted Highlight", and the channel menu "Clear Message Log" (the Clear Logs setting clears everything). Long-press actions such as Reply stay available on deleted messages and fail on Discord's side. |
| MessageLoggerEnhanced | Partial | Merged into MessageLogger instead of a separate plugin (they conflict on PC). Ported: ghost ping detection (a toast when a single deleted message mentioned you or @everyone; bulk deletes are only logged), the log page (Open Logs) with All / Deleted / Edited / Ghost Pinged filters and long press to copy, and "Keep Log After Restart", which saves the log (not the chat state) in the app's private storage. Not ported: export/import, saving deleted attachments, whitelist/blacklist, muted server/channel options and time-based cleanup. |
| AntiDeleteMessage | Skipped | It re-posts your messages when someone else (usually a moderator) deletes them, which circumvents moderation. |
| SilentEdit | Ported | Hides the "(edited)" tag on all of your own messages, on your device only. PC only hides it for messages edited during the current session. |
| NoBlockedMessages | Partial | Messages from blocked users are removed from the chat list completely instead of the "blocked messages" bar, and the chat updates when you block or unblock someone. The "ignore incoming messages" option is not ported (their messages can still count as unread), and the legacy app has no "ignored users". |
| BlockKeywords | Partial | Messages whose text, embed title or embed description match a blocked word (whole word, or regular expression with Use Regex; optional Case Sensitive) are removed from the chat list. PC shows them as blocked messages instead, but the Android app decides blocking per author, not per message, so there is no per-message "blocked" bar to reuse. The regex helper and the "ignore new messages bar" option are not ported. |
| ClientSideBlock | Partial | Hides messages from the listed user IDs, and from blocked users when Hide Blocked Users is on, at the chat list model level. Reply previews of their messages show "↓ Replying to blocked message" or disappear (Blocked Reply Display). Not ported: hiding users in the member list, friends list, DM list, Active Now and voice channels, empty role headers, and the server black/white lists. |
| HideMessages | Partial | "Hide" in the message long-press menu removes a message from the chat until restart; "Show Hidden Messages" in the settings brings them all back. Hiding DMs from the DM list is not ported. |
| iLoveSpam | Not applicable | The legacy Android app doesn't hide messages from likely spammers, so there is nothing to turn off. |
| ContentWarning | Partial | When a message's text contains a flagged word (ignoring case), the text is shown as one spoiler and its attachments get the spoiler cover; tapping reveals them. Mobile has no hover, so the "show on click" option doesn't apply, and embeds are not covered. |
| BlurNSFW | Partial | Attachments in NSFW channels (and their threads) get Discord's spoiler cover until tapped, instead of a blur until hovered. Embeds are not covered and there is no blur amount setting. |
| RevealAllSpoilers | Ported | "Reveal All Spoilers" in the message long-press menu replaces Ctrl-click: it reveals every text spoiler and spoiler attachment of the message. Spoilers inside embeds and Ctrl+Shift-click (whole chat) are not ported. |
| StickerBlocker | Ported | "Block Sticker" / "Unblock Sticker" in the message long-press menu. Blocked stickers are removed from the chat list and the message shows "Blocked sticker" (with ID and name when Show Message is on) instead of PC's cat GIF. The list is stored in the same format as PC. Blocking from the sticker picker is not ported. |
| WhitelistedEmojis | Skipped | It filters the emoji picker and autocomplete to a whitelist managed from emoji context menus; the Android emoji picker would need its own whitelist editor, which this batch doesn't add. |
| HideMedia | Ported | "Hide Media" / "Show Media" in the message long-press menu instead of a hover button. Attachments, embeds, stickers and components of the message are removed from the chat list and a "Media Hidden" note is shown. The list is saved across restarts, like on PC (up to 1000 messages). |
| EventLogs | Skipped | The voice, friend and server event log with its header bar button is not ported. MessageLogger's log page covers deleted and edited messages and ghost pings. |
| SilentDelete | Ported | "Silent Delete" in the long-press menu of your own messages and `/silentpurge` (1-100 of your recent messages in the channel), with PC's placeholder-then-delete sequence and its settings. Not ported: the icon accent color and "Silent Delete History" for already deleted messages. |
| ClearMyMessages | Skipped | Wiping your whole history in a channel through repeated search and scan passes is not ported. `/silentpurge` from SilentDelete deletes up to 100 of your recent messages. |
