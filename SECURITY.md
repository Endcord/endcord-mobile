# Security policy

## Supported versions

Only the latest Endcord build (delivered through the in-app updater) and the latest Endcord Installer release
receive fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems, such as a way for a plugin or a message to read
your Discord token, run code, or access files it shouldn't.

Report it privately instead through GitHub: **Security → Report a vulnerability** on this repository. Include
the steps to reproduce it and the Endcord and Android versions. You will get an answer as soon as possible, and
credit in the release notes if you want it.

## Plugins

Plugins run with full access to your Discord account. Only install plugins from sources you trust. The plugins
built into Endcord are reviewed as part of this repository.
